lightdm 根因（已实测确认）
--------------------------
/var/log/lightdm/x-0.log：
  (EE) Cannot run in framebuffer mode. Please specify busIDs for all framebuffer devices

X 自己的日志把原因写得很清楚：
  (II) xfree86: Adding drm device (/dev/dri/card1)
  (II) xfree86: Adding drm device (/dev/dri/card0)
  (II) no primary bus or device found
          falling back to /sys/devices/platform/27700000.npu/drm/card1

card1 是 RKNPU（drivers/rknpu/rknpu_drv.c:862 无条件 drm_dev_alloc，NPU 要用 GEM
做 dma-buf），card0 才是 rockchip-drm。NPU 比显示子系统 probe 得早，X 的平台探测
取第一个 DRM 设备当主设备 → 选中 NPU → 没有 CRTC → Fatal → lightdm 反复重启后
start-limit-hit；plymouth-quit 的 failed 是 lightdm 的 OnFailure= 连带。

单独加 Option "kmsdev" "/dev/dri/card0" 不够（screen 用 card0，但主设备仍是 NPU，
xf86BusConfig 阶段照样 Fatal）。必须用 OutputClass 改主设备。

本版改动
--------
1. 新增 overlay/common/etc/X11/xorg.conf.d/10-rockchip-primary.conf：
     Section "OutputClass"
         Identifier  "RockchipDRM"
         MatchDriver "rockchip"
         Option      "PrimaryGPU"     "yes"
     EndSection
   MatchDriver 匹配 rockchip_drm_driver.name = "rockchip"，NPU 是 rknpu，只匹配显示子系统。
   与厂商 debian12/overlay/etc/X11/xorg.conf.d/20-modesetting.conf 同源。
2. lubancat-3.conf / lubancat-5.conf 桌面段各补一条 install
3. check_l3_ui.sh B 段加 3 项断言（文件存在 / MatchDriver / PrimaryGPU）
